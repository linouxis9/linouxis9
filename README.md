- 🔭 I’m the lead developer and maintainer of [PacketRusher](https://github.com/HewlettPackard/PacketRusher), a high-performance tool dedicated to the validation of 5G Core networks.
- 🚀 I’m also working on OxiRush, a set of Rust libraries for fast prototyping and testing of 5G and LTE/EPS core-network functions:
  - [oxirush-nas](https://github.com/linouxis9/oxirush-nas) — 5GS and EPS NAS codec for TS 24.501 and TS 24.301, with validation and NAS security.
  - [oxirush-security](https://github.com/linouxis9/oxirush-security) — 5GS and EPS key derivation, ciphering and integrity algorithms, and SUCI, per TS 33.501 and TS 33.401.
  - [oxirush-ngap](https://github.com/linouxis9/oxirush-ngap) — 5G NGAP codec for TS 38.413, generated from ASN.1.
  - [oxirush-s1ap](https://github.com/linouxis9/oxirush-s1ap) — LTE/EPS S1AP codec for TS 36.413, with the same API as oxirush-ngap.
  - [oxirush-sctp](https://github.com/linouxis9/oxirush-sctp) — async SCTP sockets for Tokio on Linux.
  - [oxirush-gtp-u](https://github.com/linouxis9/oxirush-gtp-u) — GTP-U codec, endpoint and test UPF for TS 29.281, with an eBPF fast path.
