<h3 align="center">Site Reliability Engineer + Software Engineer in 5G Core Networks</h3>

- 🚀 I am currently working on OxiRush, a set of Rust libraries for fast prototyping and testing of 5G and LTE/EPS core-network functions:
  - [oxirush-nas](https://github.com/linouxis9/oxirush-nas) ([crate v0.4.0](https://crates.io/crates/oxirush-nas/0.4.0)) — 5GS and EPS NAS encoding and decoding for 3GPP TS 24.501 and TS 24.301, with typed IEs, validation, wire-preserving round trips, and optional NAS security.
  - [oxirush-ngap](https://github.com/linouxis9/oxirush-ngap) ([crate v0.4.2](https://crates.io/crates/oxirush-ngap/0.4.2)) — 5G NGAP APER codec for 3GPP TS 38.413, generated from ASN.1 with typed helpers and examples.
  - [oxirush-s1ap](https://github.com/linouxis9/oxirush-s1ap) ([crate v0.2.0](https://crates.io/crates/oxirush-s1ap/0.2.0)) — LTE/EPS S1AP APER codec for 3GPP TS 36.413, with an API matching oxirush-ngap.
  - [oxirush-security](https://github.com/linouxis9/oxirush-security) ([crate v0.2.0](https://crates.io/crates/oxirush-security/0.2.0)) — 5GS and EPS KDFs, NEA/NIA and EEA/EIA algorithms, NAS security contexts, SUCI, and interworking per TS 33.501 and TS 33.401.
